# AGRADECIMENTOS

## **Liderança Técnica e Desenvolvimento de Talentos: O Projeto LexPay**

Recentemente, tive a oportunidade de liderar o desenvolvimento da **LexPay**, uma API REST estruturada para a gestão e negociação de precatórios. Mais do que um desafio técnico, este projeto nasceu como uma iniciativa estratégica de capacitação, utilizando o sistema **Celer da Ativos** como referência de negócio para o treinamento prático de desenvolvedores Juniors.

### **O Desafio da Arquitetura e Gestão**

Sob a aprovação do nosso CTO na Ativos, **Jarbas Gouveia**, assumi a responsabilidade pela arquitetura do sistema e pelo gerenciamento da equipe. O objetivo era construir um ecossistema robusto que conectasse cedentes, brokers e advogados, permitindo desde a due diligence até a geração de propostas financeiras.

Neste processo, orientei os desenvolvedores **Mainaldo Santana** e **Everton Silva**, focando em boas práticas de desenvolvimento, padrões de API e integração de dados.

### **Stack Tecnológica e Estrutura**

Para garantir escalabilidade e segurança, optamos por um ecossistema moderno:

* **Backend:** Python 3.12 e Django 6.0 com Django Rest Framework (DRF).
* **Segurança:** Autenticação via JWT (Simple JWT) e gestão de permissões.
* **Banco de Dados:** PostgreSQL 17, orquestrado via Docker para isolamento de ambiente.
* **Documentação:** Implementação com drf-spectacular, garantindo que cada endpoint fosse devidamente mapeado.

### **Principais Funcionalidades Implementadas:**

* Gestão de ativos judiciais e anexação de documentos.
* Fluxo automatizado de Due Diligence.
* Cálculo financeiro para propostas de antecipação.
* Trilha de histórico para auditoria de operações.

Acredito que o papel de um líder vai além de revisar código; trata-se de criar um ambiente onde profissionais em início de carreira possam atuar em cenários reais, com tecnologias de ponta, elevando o nível de entrega da organização.
